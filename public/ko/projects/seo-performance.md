# SEO & 성능 전환

## 왜 중요한가

부톡의 공개 웹 페이지는 검색 가능하고 빨라야 했습니다. 부동산 제품에서 검색엔진이 제대로 색인하지 못하고 사용자가 느리게 경험하는 공개 웹 표면은 성장 채널이 될 수 없습니다.

## 문제

웹 스택은 클라이언트 렌더링과 정적 동작에 크게 의존했습니다. 중요한 아파트/매물 페이지는 검색엔진에 안정적으로 보이지 않았고, 사이트맵 범위는 매우 작았으며, PageSpeed는 약 20 수준이었습니다.

## 산출물

- 공개 웹 경로를 SSR 가능한 프로덕션 호스팅으로 전환했습니다.
- 매물/아파트 페이지를 위한 동적 사이트맵 생성을 구축했습니다.
- canonical URL, clean routing, 구조화 데이터, AI 검색 크롤러 대응을 추가했습니다.
- LCP 최적화, render waterfall 제거, 무거운 SDK lazy loading, 번들 정리, skeleton loading을 단계적으로 진행했습니다.

## 임팩트

공개 웹 표면을 유입 채널로 바꾼 작업이었습니다.

## Search Console 릴리스 주석

주요 웹 업데이트 직후 Search Console에 수동 주석을 남겨 두었습니다. 아래 수치는 각 주석일 기준 28일 전후의 Web 검색 지표입니다. 릴리스 전후에 관측된 추세를 보여주며, 단일 원인으로 인과를 단정하지 않습니다.

| 릴리스/업데이트 | 바뀐 점 | Search Console 추세 |
|------------------|---------|---------------------|
| 2026년 1월 redirect/canonical 정리 | trailing slash 흔들림을 없애고 `www` 리다이렉션 정리 | 28일 클릭/일 **+142%**, 노출/일 **+45%**, 평균 게재순위 **7.49 -> 6.59** |
| 2026년 2월 web v3.5.0 성능 릴리스 | 웹 번들의 barrel import 비용 제거 | lag-aware 기준 노출/일 **+36%**, 평균 게재순위 **5.99 -> 5.53**; 클릭은 거의 유지 |
